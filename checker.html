모드 충돌 체크

창작마당 모음집 주소를 넣으면 모드 수에 따라
충돌이 날 수 있는 경우의 수를 계산해 줍니다.

① 창작마당 모음집 주소

② 모드 목록 (불러오면 자동으로 채워지고, 직접 고쳐도 됩니다)

자동 불러오기가 안 될 때
  1. 브라우저에서 창작마당 모음집 페이지를 엽니다.
  2. 키보드로 Ctrl + U를 누릅니다. (맥: Option + Command + U) 소스 보기 창이 열립니다.
  3. Ctrl + A로 전체 선택, Ctrl + C로 복사합니다.
  4. 위 ② 칸에 붙여넣고 분석하기를 누르면 모드 목록을 자동으로 뽑아냅니다.

분석 결과

충돌이 의심될 때 직접 확인하는 법

  • 게임을 실행한 뒤 사용자 폴더의 Zomboid/console.txt를 열어 ERROR나 LUA 오류가 나는 줄을 찾아보세요. 오류 줄에 모드 이름이 같이 찍히는 경우가 많습니다.
  • 모드를 절반씩 꺼 가며 문제가 사라지는 쪽을 좁혀 가면 원인 모드를 빠르게 찾을 수 있습니다.
  • 모드 로드 순서를 바꿔 보세요. 같은 파일을 덮어쓰는 경우 나중에 로드된 쪽이 적용됩니다. 서버라면 설정 파일의 Mods=, Map= 순서를 확인하세요.
  • 각 모드의 설명란과 댓글에 "호환 안 됨", "같이 쓰면 오류" 같은 안내가 있는지 확인하세요.
